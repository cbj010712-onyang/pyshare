# 파이썬 코드 공유방 (온양고 멘토링)

학생이 **학번·이름·비밀번호 4자리**로 들어와서 파이썬 코드를 **저장**하고, 브라우저에서 바로 **실행**하고,
친구들이 공개한 코드를 **구경하고 고쳐서 돌려 볼 수** 있는 사이트예요.
저장할 때마다 **버전**이 쌓이고, 멘토는 버전마다 **피드백**을 남길 수 있어요.
**주차별 활동지**를 공유방 안에서 쓰면 답이 자동 저장되고, [제출하기]를 누르면 **항목별 답**과 자동으로 만든 **활동지 이미지**가 DB에 저장돼요.
코드도 주차를 골라서 만들 수 있어요.

## 폴더 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 한 페이지 안에 로그인 · 목록 · 프로젝트 · 학생 관리 화면이 다 있어요 (`#home`, `#p12`, `#members`) |
| `config.js` | Supabase 주소와 키 (여기만 고치면 돼요) |
| `week2.html`, `week3.html`, `week4.html` | 주차별 활동지 (원래 활동지 + 공유방 저장 연결) |
| `js/weeks.js` | 2~6주차 목록: 주차 목표, 할 일 목록, 활동지 파일 이름, 분야별 예시 코드 (내용을 바꿀 때 여기만 고쳐요) |
| `js/sheet-bridge.js` | 활동지 ↔ 공유방 다리: 로그인 확인, 자동 저장, 항목 뽑기·제출, 이미지 받기, 지난주 활동지 불러오기 |
| `js/zip.js` | 결과물 묶음(zip) 만들기. 라이브러리 없이 브라우저에서 바로 만들어요 |
| `css/sheet.css` | 활동지 모양을 공유방과 맞추는 스타일 (원래 활동지 스타일 다음에 불러와서 덮어써요) |
| `sw.js` | 예비 **input() 다리** (서비스 워커). 실시간 입력으로 못 바꾸는 드문 코드에서만 써요 (꼭 사이트 맨 위 폴더에) |
| `js/app.js` | 화면 그리기, 저장, 버전, 피드백, 학생 관리 |
| `js/api.js` | Supabase 함수 부르기 (`/rest/v1/rpc/cs_...`) |
| `js/runner.js` | 파이썬 실행기 (화면 쪽): 워커 만들기, 출력 받기, 입력 보내기, 멈춤 |
| `js/py-worker.js` | 파이썬 실행기 (워커 쪽): Pyodide로 코드 실행, 오류 줄 찾기, 한글 도움말 |
| `js/mock.js` | 체험 모드 (config.js 가 비어 있을 때) |
| `css/style.css`, `css/codemirror.css` | 모양, 코드 편집기 기본 모양 (CodeMirror 5, MIT) |
| `supabase_codeshare.sql` | Supabase에 한 번 붙여 넣어 실행하는 파일 · **깃허브에 올리지 않아요** |

## 설치 (퀴즈 때와 거의 같아요)

1. **Supabase**: 퀴즈와 같은 프로젝트를 써도 돼요 (표 이름이 `cs_`로 시작해서 안 섞여요).
   SQL Editor → New query → `supabase_codeshare.sql` 전체 붙여 넣고 Run.
2. 새 query에서 멘토 비밀번호를 정해요 (10글자 이상, 퀴즈 관리자 비밀번호와 다르게):
   `select cs__set_mentor_password('여기에-긴-비밀번호');`
3. **GitHub**: 새 저장소(예: `py-share`, Public) → 압축파일의 **`1_upload_to_github` 폴더 안의 내용물**을 폴더 구조 그대로 올려요.
   `2_do_not_upload`(supabase_codeshare.sql)은 올리지 않아요. `config.js`는 빈 채로 올리지 말고, 먼저 값을 채워요.
4. `config.js`에 Project URL과 Publishable key를 넣어요 (퀴즈 config.js 값과 같아요). secret 키는 절대 안 돼요.
5. Settings → Pages → Branch `main` / `(root)` → Save. 주소: `https://아이디.github.io/py-share/`
6. 사이트 로그인 화면에서 **[멘토] 탭 → 멘토 비밀번호** → 학생 관리 → 학번·이름으로 명단을 등록해요
   ("여러 명 한 번에 추가"에 `10101 김민수`처럼 한 줄에 한 명씩 붙여 넣어도 돼요).
7. 학생은 학번·이름을 적고, 처음 들어올 때 비밀번호 4자리를 정해요 (두 번 적어서 확인).
   잊었거나 10번 틀려서 잠기면 멘토가 [비밀번호 초기화]를 눌러 줘요.

`config.js`가 비어 있으면 체험 모드예요. 학생 `10101 김민트 / 1111`, `10102 이감자 / 2222`,
처음 오는 학생 `10103 박새싹`, 멘토 `mentor-demo-1234`.

## 주차별 할 일과 예시 코드

주차 카드는 **2주차부터 6주차**까지 있어요.

| 주차 | 주제 | 활동지 |
|---|---|---|
| 2 | 분야와 주제 정하기 | week2.html |
| 3 | AI 피드백 받고 설계하기 | week3.html |
| 4 | 파이썬 실전노트로 코드 만들기 | week4.html |
| 5 | 완성하고 다듬기 | 없음 (코드 제출) |
| 6 | 발표회 | 없음 (최종 코드) |

- 주차 화면에는 **이번 주 목표**, **번호 붙은 할 일 목록**(자세한 설명 + [활동지 열기 →] / [예시 코드 보기 ↓] 바로 가기), **예시 코드 카드**가 있어요.
  할 일 체크 표시는 학생 기기에만 남아요 (진짜 제출 여부는 활동지·코드로 확인해요).
- 예시 코드는 분야별(① 데이터 분석 / ② 미니 웹앱 / ③ AI 윤리·보안)로 있고, 학생이 활동지에서 고른 분야가 맨 앞에 와요.
  [이 예시로 코드 시작]을 누르면 그 주차 코드가 만들어지고, 맨 위에 제목·만든 사람·시작한 예시 주석과 `# 할 일` 안내가 붙어요.
  [+ 새 코드]에서도 주차를 고르면 **시작 코드**를 고를 수 있어요.
- 멘토 화면에서는 할 일과 예시 코드가 **접었다 펴는 칸**에 들어 있어요.
- 내용 고치기: `js/weeks.js`에서 주차마다 `goal`(목표), `todo`(할 일: `t` 제목, `d` 설명, `sub` 세부 목록, `act`에 `'sheet'`이나 `'code'`),
  `examples`(예시: `id`, `field`는 `data`/`web`/`sec`/`all`, `title`, `desc`, `code`)를 바꿔요.
  `code` 안에서 줄바꿈은 `\n`, 큰따옴표는 `\"`로 적어야 해요. 고친 뒤 `index.html`의 `?v=` 숫자를 바꾸면 학생 브라우저가 새 파일을 받아요.
- 예시 코드 11개는 모두 브라우저 파이썬(Pyodide)에서 실행해 확인했어요.

## 주차별 활동지

- 학생: 목록 맨 위 **주차 카드** → 그 주 화면에서 [활동지 쓰기]. 쓰는 대로 공유방에 저장되고(다른 기기에서도 이어서),
  다 쓰면 [제출하기] → 화면의 모든 항목(구역 · 질문 · 답)이 `cs_sheet_items`에 한 줄씩, 활동지 이미지가 `cs_sheets`에 저장돼요.
  제출한 이미지는 활동지 위쪽 띠의 [제출한 이미지 받기], 주차 화면의 [이미지로 받기]로 언제든 내려받아요. 다음 주 활동지에서 **지난주 활동지 이미지 받기** 버튼으로 AI에게 올릴 이미지를 받아요.
- 학번·이름은 로그인 정보로 자동으로 채워지고 고칠 수 없어요.
- 멘토: 주차 화면에서 학생별 **제출 / 작성 중 / 아직**, 진행률, 주제, 이번 주 코드를 한눈에 봐요. [이미지]에서 이미지와 **항목별 답**을, [답 보기]로 활동지 화면 그대로(읽기 전용) 봐요.
  [항목별 답 CSV 받기]를 누르면 학생 × 항목 표가 엑셀용 CSV로 내려받아져요.
- 새 활동지를 추가하려면: 기존 활동지(아티팩트)를 `week5.html`로 저장하고 다음 4군데를 바꾼 뒤 `js/weeks.js`에 적어요.
  `week4.html`을 열어 `SheetBridge`가 나오는 곳을 보면 그대로 따라 할 수 있어요.
  1. `<title>` 아래에 스크립트 5줄 (`data-week="5"`), `</head>` 앞에 `css/sheet.css`
  2. `const KEY = SheetBridge.key('...')`
  3. 맨 끝 시작 줄을 `SheetBridge.start(KEY, () => { ... })`로 감싸기
  4. 제출 버튼에서 `await SheetBridge.submit(canvas)`, 파일 저장 버튼에서 `SheetBridge.download(...)`
- 활동지 이미지는 폭 900px JPEG로 줄여서 데이터베이스에 저장해요 (한 장에 보통 0.2~0.6MB, 3MB까지).

## 화면 쓰는 법 (편의 기능)

- **학생 첫 화면**: 맨 위에 *이어서 할 주차*(아직 안 끝낸 첫 주차, 할 일 진행 막대, 바로 가기)와 *최근에 고친 코드*가 나와요.
  주차 카드에는 **지금** / **✓ 끝** 표시가 붙어요. 끝난 기준: 활동지가 있는 주는 제출, 없는 주는 그 주 코드가 하나라도 있으면.
- **찾기**: 목록의 찾기 칸(키보드 `/`)에 이름이나 제목을 적으면 바로 걸러져요. 주차 칩과 함께 쓸 수 있어요.
- **주차 화면**: 할 일 중 아직 안 한 첫 번째에 **다음** 표시가 붙고, 진행 막대가 차요. 컴퓨터에서는 오른쪽 활동지·내 코드 칸이 스크롤해도 따라와요. 휴대폰에서는 활동지·내 코드 칸이 할 일보다 위에 와요.
- **돌아가기**: 주차 화면에서 연 코드는 [← N주차]로, 목록에서 연 코드는 [← 목록]으로 돌아가요.
- **멘토**: 목록에서 학생을 드롭다운으로 골라요. 주차 화면 위쪽에 제출 수와 진행 막대가 있고, [제출 / 작성 중 / 아직]을 누르면 그 학생들만 보여요.
- 휴대폰에서는 주차 카드를 옆으로 밀어서 보고, 코드 카드는 미리 보기 없이 짧게 보여요. 밝은·어두운 화면 모두 지원해요.

## 완성작과 웹앱 (친구 작품 공개 방법)

- 기본은 **완성작만**이에요. 친구들 화면에는 친구가 **[★ 완성작으로 내기]** 를 누른 프로젝트가 **웹앱으로만** 보여요.
  친구 코드, 버전 기록, 피드백은 안 보여요. 웹앱이 아직 없으면 카드에 "웹앱 준비 중…"이 떠요.
- 학생: 프로젝트 화면의 [★ 완성작으로 내기] (저장하지 않은 코드가 있으면 먼저 저장하라고 안내해요). 학생마다 완성작은 하나이고, 다시 눌러 바꾸거나 취소할 수 있어요.
- 멘토: 첫 화면의 **친구 코드 공개** 칸에서 `주차별 모두 / 완성작만 / 안 보임`을 바꿔요. 완성작 낸 학생 수와 웹앱 수가 보여요.
  `주차별 모두`에서는 지금까지처럼 공개한 친구 코드를 열어 볼 수 있어요.
- 공개 방법은 화면에서 숨기는 게 아니라 **데이터베이스 함수에서** 막아요. 주소를 직접 쳐도 친구 코드는 안 열려요.

### 웹앱 올리기 (멘토)

1. 완성작 프로젝트에서 **[🖥 웹앱 만들기]** → 버전 고르기 (기본은 완성작 버전) → **[프롬프트 복사]**
2. claude.ai에 붙여 넣고, 받은 답을 그대로 **붙여 넣기 칸**에 넣어요 (` ```html ` 표시는 저절로 빼요).
3. **[미리 보기]** 로 확인하고 **[저장]**. 완성작만 모드에서는 바로 친구들에게 보여요.
   학생이 완성작을 새 버전으로 바꾸면 "새로 만들면 좋아요" 안내가 떠요.

- 웹앱은 `sandbox="allow-scripts allow-forms allow-modals"` iframe(같은 출처 권한 없음) 안에서 돌아가요.
  그래서 웹앱 코드가 공유방의 로그인 정보(localStorage), 쿠키, 화면에 접근할 수 없어요 (테스트로 확인했어요).
  같은 이유로 웹앱 안에서는 localStorage를 쓸 수 없어서, 프롬프트에 쓰지 말라고 적어 두었어요.
- 웹앱 HTML은 60만 글자까지 저장돼요. 프롬프트 문장은 `js/app.js`의 `waPrompt`에서 고칠 수 있어요.
- 이 기능을 쓰려면 `supabase_codeshare.sql`을 **한 번 더 실행**해야 해요 (기존 코드·학생·활동지는 그대로 남아요).

## 지난주 결과물 불러오기 (보충·수정)

- **코드:** 주차 화면의 **이번 주 내 코드** 칸에 **[↻ 지난 코드 불러오기]** 가 떠요. 바로 앞 주차의 내 코드를 골라 줘요
  (완성작 → 최근에 고친 것 순서). 누르면 그 코드의 마지막 저장본을 **복사해서** 이번 주 코드로 새로 만들어요.
  - 지난주 코드는 그대로 남아서, 주차마다 무엇을 했는지 기록이 남아요.
  - 맨 위 주석이 `# 제목 (5주차)` 로 바뀌고 `# 불러온 코드: 4주차 「제목」 v3` 한 줄이 붙어요.
  - [+ 새 코드] 창의 **시작 코드**에서도 "↻ 내 지난 코드 불러오기"로 아무 주차의 내 코드를 고를 수 있어요.
- **활동지:** 3·4주차 활동지 위쪽에 **[↻ 지난주 활동지 불러오기]** 띠가 있어요 (주차 화면의 "↻ 2주차 활동지 불러와서 쓰기" 링크로 열어도 돼요).
  - 누르면 지난주 답이 **옆 칸**(휴대폰은 아래 칸)에 떠요. 항목마다 **[복사]** 가 있어서 보면서 보충하고 고쳐 쓸 수 있어요.
  - **분야와 주제**는 비어 있으면 저절로 채워요 (2주차 "나는 … 위해 … 만들어서 …" 문장 → 3주차 주제). 이미 적었으면 덮어쓰지 않고 [이 주제로 바꾸기] 버튼만 보여 줘요.
  - 항목별 답은 **[제출하기]를 누른 활동지만** 보여요. 제출한 활동지 이미지도 그 칸에서 열 수 있어요.
  - 채우는 방법은 각 활동지의 `window.SheetCarry` 에서 정해요 (week3.html, week4.html 맨 아래).

## 최종 결과물 내려받기

- **학생:** 첫 화면 "내 코드" 옆 **[⬇ 내 결과물]**, 또는 6주차 화면의 **[⬇ 내 결과물 내려받기]** → zip 파일 하나로 받아요.
- **멘토:** 첫 화면 "친구 코드 공개" 칸의 **[⬇ 결과물 받기 (zip)]** → 학생 전체 또는 한 명을 골라요. 학생마다 폴더 하나씩 들어가요.
- 묶음 안 (학생 폴더 `10101_이름_결과물/`):

  | 폴더 · 파일 | 들어 있는 것 |
  |---|---|

## 꼭 알아 둘 것

- 명단에는 **학번과 이름**이 저장되고, 친구들 화면에는 **이름**만 보여요 (학번은 멘토만 봐요).
  비밀번호는 바꾼 값(bcrypt)으로만 저장돼서 멘토도 볼 수 없어요. 코드 안에는 개인정보를 쓰지 않게 안내해요.
- 비밀번호를 초기화한 뒤에는 학생이 바로 들어와 새 비밀번호를 정하게 해 주세요 (먼저 정한 사람이 주인이 돼요).
- 친구 코드는 친구 브라우저의 **별도 공간(워커)** 에서 돌아가요. 워커는 로그인 정보(localStorage)를 못 읽어요.
- `input()`은 **실시간**으로 받아요. 실행하다 `input()`을 만나면 실행 결과 칸에 입력칸이 뜨고, 적고 Enter를 누르면 이어서 실행돼요.
  (실행 전에 코드의 `input()`을 "기다릴 수 있는" 호출로 바꿔서 돌려요. 줄 번호와 오류 안내는 그대로예요.
  함수 안, 반복문, 클래스 메서드, `__init__`, 상속, 딕셔너리에 담은 함수 모두 돼요.)
  아주 드물게 lambda나 클래스 본문 바로 안에서 `input()`을 쓰면 예비 방식(서비스 워커)을 쓰고, 그것도 안 되는 곳에서는 옮기라는 안내가 나와요.
- 쓸 수 있는 모듈: 파이썬 기본 모듈(random, math, time 등), numpy, matplotlib(그래프 글자는 영어로).
  `turtle`, `pygame`, `tkinter`는 브라우저에서 안 돼요.
- 코드를 고치면 이 기기에 **임시 저장**돼요. 새로고침해도 이어서 보여 주고, [저장]을 눌러야 버전이 생겨요.
